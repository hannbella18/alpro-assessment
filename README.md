# Pharmacy Stock Management System

A simple Java-based stock management application developed for a practical coding assessment.

## Features
- **Product Management:** Display product name, SKU, quantity, and expiry date.
- **Stock Adjustment:** Add or deduct stock quantities.
- **Input Validation:** Reject invalid inputs and prevent negative stock.
- **Low Stock Alert:** Display warnings when stock is 5 units or below.
- **Expiry Date Tracking:** Alert users when products have expired or will expire within 30 days.

## Technologies Used
- Java
- Arrays and Object-Oriented Programming (OOP)
- Scanner and LocalDate
